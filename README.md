# SPACE LEGACY

## 🚀 Project Overview

Interactive storytelling platform about NASA's robotic explorers left behind on the Moon and Mars.

**Challenge:** NASA Space Apps Challenge 2026  
**Theme:** Abandoned but Not Forgotten: Storytelling about NASA's Discarded Equipment on the Moon and Mars

## ✨ Features

- **Professional UI Design** - Modern, sleek interface with gradient effects
- **Smooth Animations** - Starfield background, hover effects, transitions
- **Fully Responsive** - Works perfectly on desktop, tablet, and mobile
- **Interactive Missions** - Explore 3 legendary robotic explorers
- **Dynamic Timeline** - Tabbed navigation showing mission events
- **Knowledge Quiz** - Test your knowledge with 5 questions
- **Impact Section** - Learn about the legacy of these missions
- **Fast Performance** - Optimized images and smooth 60fps animations

## 🌙 Missions Covered

1. **Apollo Lunar Roving Vehicle**
   - Destination: The Moon
   - Years: 1971-1972
   - Distance: 79 km across 3 missions
   - Samples: 385 kg collected

2. **Sojourner Mars Rover**
   - Destination: Mars
   - Years: 1996-1997
   - Distance: 104.6 meters
   - Duration: 83 sols (Martian days)

3. **Mars Pathfinder Lander**
   - Destination: Mars
   - Years: 1996-1997
   - Images: 16,500 transmitted
   - Duration: 83 sols

## 💻 Technologies Used

- **HTML5** - Semantic markup and structure
- **CSS3** - Modern styling with gradients, animations, flexbox, grid
- **JavaScript (Vanilla)** - No frameworks, pure JavaScript
- **Canvas API** - Animated starfield background
- **Responsive Design** - Mobile-first approach
